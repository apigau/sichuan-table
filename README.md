# Sichuan Table

Public English marketing site for **Sichuan Table** (@sichuantable)—small-group culinary trips in Chengdu & Chongqing.

Static HTML/CSS/JS. Designed for GitHub Pages (root of `main`).

## Pages

- `index.html` — home
- `trip.html` — itinerary outline & inclusions
- `trust.html` — trust, payments, refunds
- `book.html` — booking steps & interest form
- `medical.html` — hospital accompaniment placeholder (not medical advice)

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080 --directory .
```

## Deploy

GitHub Pages: Settings → Pages → Deploy from branch `main` / root (or `/docs` if you move files).
